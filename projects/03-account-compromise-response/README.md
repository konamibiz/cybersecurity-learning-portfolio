# Project 3: User Account Compromise Response Procedure

**Status:** Planned  
**Type:** Security procedure / knowledge-base document

## Objective
Write a practical procedure for responding to a report that a user's account may be compromised.

## Scope
A fictional organisation's standard user account. Follow the organisation's approved processes and escalate actions requiring security or identity-administration privileges.

## Procedure outline
- [ ] Receive and record the report.
- [ ] Verify the requester's identity using an approved process.
- [ ] Record relevant times, symptoms, and affected services.
- [ ] Escalate to the security team according to severity and policy.
- [ ] Have authorised personnel secure the account and active sessions.
- [ ] Review relevant logs and preserve evidence according to policy.
- [ ] Restore access safely and confirm with the user.
- [ ] Document root cause if established, actions taken, and closure.
- [ ] Recommend preventative improvements.

## Deliverables
- Step-by-step procedure
- Incident ticket template
- Closure checklist
- Short explanation of assumptions and limitations
