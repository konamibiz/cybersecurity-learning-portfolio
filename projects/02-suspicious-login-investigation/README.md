# Project 2: Simulated Suspicious Login Investigation

**Status:** Planned  
**Type:** Log-analysis exercise  
**Data:** Synthetic training data only

## Objective
Practise reviewing authentication events, identifying patterns that warrant further investigation, and documenting a cautious response.

## Scenario
A fictional user's account has several failed sign-in attempts followed by a successful sign-in. The exercise is to assess whether the events are suspicious and what additional evidence is needed.

## Method
1. Describe the fields available in the synthetic log.
2. Establish a basic timeline.
3. Identify unusual patterns without assuming that one indicator proves compromise.
4. List follow-up checks and evidence needed.
5. Recommend authorised containment and escalation steps.
6. Write a short incident report.
